# SMTMS (Supplier Material Traceability Management System) - Software Requirements Specification

## 文件資訊
- 版本：1.0.0
- 最後更新：2026-10-20
- 依據：本文件與 `02_DOMAIN_RULES.md`、`04_API_CONTRACT.md`、`05_DATABASE_SCHEMA.md`、`06_CURRENT_STATE.md`、`07_ACCEPTANCE.md`、`08_ROADMAP.md` 為目前維護中的正式規格文件。

## 1. 系統目標
解決SMT電子製造業中，供應商物料追溯的痛點：
- 追溯鏈中斷：無法從最終產品反向追蹤到原始供應商批次
- 品質問題反應緩慢：發生不良時無法快速隔離受影響批次
- 手動記錄易出錯：依賴Excel或紙本記錄，容易發生資料不一致
- 缺乏品質管理流程：IQC檢驗、不合格品處理無系統化記錄

## 2. 核心使用者角色
### 2.1 系統定義的使用者類型
| 角色 | 職責 |
|------|------|
| 採購人員 | 維護供應商資料、建立供貨關聯 |
| 收料人員 | 處理廠商送料、建立收料單、拆分內部批次 |
| IQC檢驗員 | 執行進料檢驗、判定品質狀態 |
| 品保工程師 | 處理不合格品、啟動CAPA流程 |
| 系統管理員 | 管理使用者權限、系統設定 |

## 3. MVP 功能範圍
### 3.1 必備功能（MVP內）
#### 基礎主檔管理
- ✅ 供應商管理：新增、查詢、更新供應商基本資料
- ✅ 物料管理：新增、查詢、更新物料基本資料
- ✅ 供貨關聯：建立供應商與物料的供應關係，支援設定首選供應商
- ✅ 供應商資格文件：查詢供應商相關證書文件（僅查詢）

#### 收料與追溯
- ✅ 收料管理：建立收料單、記錄廠商送料資訊
- ✅ 內部批次拆分：將廠商批次拆分為廠內使用的內部批次
- ✅ 批次追溯：基本的批次關聯查詢（追溯鏈可見）

#### 品質管理
- ✅ IQC檢驗：建立進料檢驗記錄、更新檢驗結果
- ✅ 檢驗狀態更新：依檢驗結果更新內部批次狀態
- ✅ 不合格品管理：記錄品質異常、啟動不合格品流程

#### 系統基礎
- ✅ JWT認證：安全的登入登出機制、Token撤銷
- ✅ RBAC權限：基於角色的權限控管
- ✅ 分頁搜尋：主要清單頁面支援分頁與關鍵字搜尋
- ✅ 健康檢查：服務健康狀態監測端點

### 3.2 非MVP功能（未來版本）
- 完整的生產工單追溯鏈
- 完整的CAPA整改流程
- 報表匯出功能
- 郵件通知系統
- 檔案上傳下載功能
- 使用者介面權限的完全可配置
- 監控與告警系統
- 資料備份與還原

## 4. 非功能性需求
### 4.1 效能需求
- 所有API回應時間 < 500ms（95百分位）
- 支援至少50名同時線上使用者
- 資料庫查詢優化，避免N+1問題

### 4.2 安全需求
- 密碼加密存儲（bcrypt）
- Token有效期限制（60分鐘）
- CORS原點限制
- 權限隔離：使用者僅能存取授權的資源

### 4.3 可用性需求
- 服務可用性 > 99.5%
- 支援Docker Compose一键部署
- 開發環境可於本機完整運行
