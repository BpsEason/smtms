## 版本規劃

### v1.0.0 - MVP 穩定版 (預定完成時間：2026-Q4末)
**目標**：修復所有已知嚴重缺陷，完成核心追溯鏈的完整性，使系統可進入試用。

#### P0 - 最高優先（必須完成）
- [ ] 修復D1: ID配置競態條件 → 改為資料庫AUTO_INCREMENT
- [ ] 修復D2: IQC建立非原子交易 → 包進同一交易區塊
- [ ] 完成供應商批次(supplier_lots)的POST/PUT/DELETE API，補全追溯鏈上游
- [ ] 補全所有缺失的自動化測試，達到核心流程80%覆蓋率
- [ ] 修復前端Dockerfile，使其建置生產環境靜態檔案
- [ ] 驗證所有驗收標準A1-A26，至少90%項目可自動驗證

#### P1 - 高優先（MVP內應完成）
- [ ] 實作追溯查詢API：`GET /trace/{lot_no}` 可反查完整履歷
- [ ] 修復D3: 單一請求內重複批號檢查
- [ ] 修復D4: IQC更新的關聯一致性驗證
- [ ] 補齊收料、內部批次、IQC的DELETE端點（軟刪除）
- [ ] 實作基本的檔案上傳功能，支援供應商資格文件

### v1.1.0 - 品保流程強化版 (2027-Q1初)
**目標**：完整的品質管理流程，支援不合格品的端到端處理。

- [ ] 完整的CAPA整改流程實作
- [x] 稽核軌跡(audit log)：重要 ORM 異動與成功登入、RBAC 查詢、後台明細及 CSV 串流匯出（完整 API 整合測試待補驗）
- [ ] 內部批次出庫扣減邏輯（對應生產領用）
- [�] 不合格品的隔離、退貨、讓步接收流程
- [ ] 基本的報表匯出功能（CSV格式）

### v1.2.0 - 企業功能擴充版 (2027-Q1末)
**目標**：適合生產環境的企業級功能。

- [ ] 使用者、角色、權限的完整管理API
- [ ] 郵件通知與待辦提醒系統
- [ ] 檔案病毒掃描機制
- [ ] 基本的監控與告警（Prometheus格式metrics）
- [ ] 資料自動備份機制

### 長期規劃 (Beyond v1.2)
- 多廠/多倉支援
- 進階分析與數據可視化
- AI預測性品質分析

## MVP 完成驗收標準
當以下條件全部滿足，即可視為MVP完成：
1. 所有P0項目已完成並通過測試
2. 所有已知的高/中嚴重性缺陷已修復
3. 核心業務流程（供應商→物料→收料→拆分→IQC→放行）可端到端走通
4. 自動化測試覆蓋核心流程的80%以上
5. Docker Compose可一鍵部署，所有服務正常啟動
6. 文件完整，新開發人員可在1天內搭建開發環境並理解系統架構
