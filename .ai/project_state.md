# SMTMS 專案狀態文件

## 目前技術版本
- 前端版本：1.0.0
- 後端版本：1.0.0
- 部署版本：v1.0.0（Docker Compose 部署）

## 已完成模組
### 核心基礎模組
- ✅ 認證授權系統（JWT + Redis Token 撤銷）
- ✅ 使用者管理（Role/Permission 機制）
- ✅ 供應商管理
- ✅ 物料管理
- ✅ 供應商批次管理
- ✅ 收料紀錄管理
- ✅ 內部批次管理
- ✅ IQC 品質檢驗
- ✅ 稽核軌跡記錄
- ✅ CSV 匯入匯出（含公式注入防護）

## 開發中模組
- ⚠️ 不合格品完整處理流程（僅完成標記）
- ⚠️ 完整雙向追溯查詢（僅完成單向查詢）
- ⚠️ 批量操作功能
- ⚠️ 報表生成功能

## 已知問題
1. 部分邊界狀態的測試覆蓋不足
2. 批量操作缺少交易原子性保護
3. 追溯查詢僅支援單向追蹤
4. 不合格品缺少自動隔離與退廠流程
5. 部分狀態轉換缺少完整的狀態機測試

## 尚未完成項目
- 📋 生產線出料追蹤
- 📋 庫存盤點功能
- 📋 供應商績效評估
- 📋 進出口報關整合
- 📋 手機端PWA適配

## 測試現況
- 單元測試覆蓋率：約65%
- 整合測試覆蓋率：約40%
- 已覆蓋核心流程：認證、供應商建立、物料建立、批次建立、基本收料流程
- 未覆蓋區域：邊界錯誤處理、併發場景、複雜狀態轉換

## 已知架構限制
1. 後端同步Session無法直接使用async Redis操作，需要將路由改為async def
2. 前端Query Key設計過於鬆散，部分頁面的快取失效策略需要優化
3. 缺少分散式追蹤與日誌聚合
4. 資料庫連線池設定需要針對生產環境優化
5. 目前僅支援單實例部署，缺少水平擴展支援
